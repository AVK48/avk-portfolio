# Claude Code instructions — AVK Portfolio

## Product goal
Build a credible, fast, accessible, recruiter-friendly portfolio for an early-career AI/ML builder.

Positioning: **AI Engineer | LLMs | RAG | Machine Learning**

Visual direction: clean light theme, restrained blue accent, strong typography, generous whitespace, editorial layout. Avoid generic gradients, excessive animation, fake dashboards, fake metrics, and decorative skill bars.

## Stack
- React + Vite
- Plain CSS in src/styles.css
- Lucide React icons
- Static deployment; no backend or paid API

## Truthfulness rules
- Never invent employers, internships, awards, certifications, outcomes, user counts, performance metrics, or proficiency levels.
- Keep project statuses honest: Built, Experiment, Learning project, or In progress.
- Treat current portfolio copy as editable starter content. Confirm unsupported claims before adding them.
- Do not publish placeholder social links or fake email addresses.
- Do not claim production readiness unless the owner confirms it.

## First tasks
1. Run npm install and npm run build.
2. Fix build errors and responsive issues.
3. Keep content data in the profile, projects, and skills constants in src/main.jsx.
4. Preserve keyboard access and visible focus states.
5. Configure GitHub Pages with base '/avk-portfolio/'.
6. Verify navigation, links, and production build.
7. Do not push changes or deploy without owner approval.

## Content to request from the owner
- Confirm public name and short bio.
- Personal LinkedIn URL and public contact email.
- Resume PDF.
- Exact repository URL for each project.
- Screenshots, demos, datasets, results, and limitations.
- Verified IEEE leadership dates and event outcomes.
- Certifications with issuer and completion date.

Make small, reviewable changes. Explain what changed and list details that still need owner verification.
